# Artwork and fonts for the Discord pictures

- `banner.jpg` and `icon.png` are Redline Gaming's own server banner and icon.
- `fonts/Teko-*.ttf` and `fonts/BarlowCondensed-*.ttf` are open fonts under the
  SIL Open Font License 1.1 (Teko by Indian Type Foundry, Barlow by Jeremy Tribby).
- `fonts/DejaVuSans*.ttf` are the DejaVu fonts, under their own free licence. They
  are the fallback for characters the other two do not have.

To change the look, replace `banner.jpg` or `icon.png` with files of the same
name. The picture code is in `rlgimage.py`.
